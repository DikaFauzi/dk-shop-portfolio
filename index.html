ABOUT THIS PROJECT

Dibuat sebagai portfolio aplikasi transaksi ringan.

DK SHOP menggunakan HTML, CSS, Vanilla JavaScript, LocalStorage, dan Canvas API. Versi ini berjalan sepenuhnya di browser sehingga cocok sebagai demo frontend. Pengembangan berikutnya dapat menambahkan autentikasi dan sinkronisasi database.
